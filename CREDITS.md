Stats HUD for The Binding of Isaac (Flash) uses the font and stat icons of External Item Descriptions (EID):
https://github.com/wofsauge/External-Item-Descriptions

# Used from EID
- Bitmap font `resources/font/eid_default*` (built from PixelMplus10)
- Stat icons from `resources/gfx/eid_inline_icons.*` (many created by biobak)
- Icon table `flash/data/eid_markup.lua` (`EID.InlineIcons`: icon frames and offsets)
